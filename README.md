Description

This program calculates how many notebooks can fit into a box, how many leftover notebooks there are, and if the box isn't filled

How to Run

Open the program file in Python

Run the program.

Enter the values for Notebooks, Nb_box

Check the how many notebooks can fit and how many leftover notebooks there are displayed on the screen.

Input Needed

Notebooks

Nb_box

Sample Output

Enter Total number of notebooks: 10
Enter how many notebooks can fit in a box: 5
Total number of notebooks: 10
number of notebooks that can fit in a box: 5
Number of full boxes: 2
Number of leftover boxes: 0.0
